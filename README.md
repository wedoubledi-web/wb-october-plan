# План октября → ноября 2026

**https://wedoubledi-web.github.io/wb-october-plan/**

Цель октября: **маржа 60 000 − расход 25 000 = ЧП 35 000.** К 11.11 темп уже с конца октября.

Две таблицы: план на каждый день октября; сверка вчера и недели с маркером «идём / не идём». План только в целых штуках. Факт — нетто-заказы WB, утром и вечером.

> Основной репозиторий `kursor-wb` — приватный, Pages там недоступен.
> Сайт публикуется в публичный `wb-october-plan` (только HTML, без токенов).

## Формулы

- шт дня = целые (метод наибольшего остатка). Половинки и 0,3 не ставим.
- кто не идёт по факту — не разгоняем (держать, не масштаб)
- Versele-Laga все в плане, наличие = сток + приход под месяц
- шт/мес = сумма 31 дня
- выполнимо = минимум(шт/мес; сток + приход)
- прибыль/шт = Pдо × маржа
- прибыль = шт/мес × прибыль/шт
- ЧП = прибыль − расход
- довезти = максимум(0; шт/мес − сток − приход)

Правки живут в браузере. «Сбросить» вернёт план на 55 / 25 / 30.
