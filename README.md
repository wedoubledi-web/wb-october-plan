# План октября 2026 — живая таблица WB

**https://wedoubledi-web.github.io/wb-october-plan/**

Отдельная страница: правишь шт/день, Pдо, маржу, сток — формулы пересчитывают месяц, прибыль и довоз.

> Основной репозиторий `kursor-wb` — приватный, Pages там недоступен.  
> Сайт публикуется в публичный `wb-october-plan` (только HTML, без токенов).

## Формулы

- шт/мес = шт/день × 31
- выполнимо = минимум(шт/мес; сток)
- прибыль/шт = Pдо × маржа
- прибыль/день = шт/день × прибыль/шт
- прибыль/мес = выполнимо × прибыль/шт
- дней = сток / шт/день
- довезти = максимум(0; шт/мес − сток)
- маржа портфеля = прибыль / Pдо

Правки живут в браузере (localStorage). «Сбросить» вернёт базу от 23.09.
